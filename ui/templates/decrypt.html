Decrypt a File

Upload an .enc.txt bundle produced by this app. The system will use the current RSA private key to recover the AES session key and then AES-decrypt the file.

The RSA keypair lives in memory only. If the server restarted since you encrypted the file, decryption will fail. Use the Keys page to inspect the current keypair.
