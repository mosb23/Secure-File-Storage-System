Secure File Storage System

Upload a file, encrypt it with AES-128 using a random session key, then protect that session key with RSA-1024. Only the RSA private key holder can recover the original file.

Hybrid Workflow

  1. Generate a random AES-128 session key + IV.
  2. Encrypt the file with AES in CBC mode.
  3. Wrap the AES key with the recipient's RSA public key.
  4. Store/send the bundle: encrypted key + IV + ciphertext.
  5. Recipient decrypts the AES key with their RSA private key.
  6. Recipient decrypts the file with the recovered AES key.
