Encrypt a File

Upload any file. The system will:

  • Generate a random AES-128 session key and IV.
  • Encrypt your file with AES in CBC mode.
  • Encrypt the AES key with the current RSA public key.
  • Bundle everything into a downloadable .enc.txt file (opens in Notepad so you can inspect the structure).

Maximum upload size: 16 MB.
